convolutional approaches for computer vision tasks. The pioneering work on ViT [1]

door to a new era of vision architecture beyond CNNs.

Algorithm
Patch Embedding and Position Encoding (Pre-processed)
In this assignment, the input image (32×32@3 channels) is divided into 4×4 patches,
giving 64 patches in total. Each patch (4×4×3 = 48 values) is flattened into a vector and
passed through a linear layer that projects it to 16 channels. This process, called patch
embedding, converts the image into 64 tokens, each with 16 channels, so the model can
process them like a sequence in a transformer.

Fig. 3 Patch Embedding
In Vision Transformers (ViT), position encoding is used to give the model information
about the spatial location of each image patch, since transformers themselves have no
sense of order. After obtaining patch embeddings, a positional embedding vector (learned
during training) is added to each token embedding elementwise. This preserves the same
dimensions while allowing the model to distinguish where each patch comes from in the
original image.

Self-attention is the core operation of the Transformer and Vision Transformer (ViT)
models. It allows the model to decide which parts of the input are most relevant when
producing each output. Each input token is first projected into three vectors — Query (Q),
Key (K), and Value (V) all with dimension 𝑐. The model computes the similarity between
every query and all keys using the dot product 𝑄𝐾 𝑇 .This produces a score matrix that
measures how much each token should “attend to” others. To keep the scale stable, the
scores are divided by √𝑐ℎ𝑒𝑎𝑑 , the square root of the dimension of each head. Then, a
Softmax function is applied to normalize these scores into attention weights that sum to
one. Finally, these weights are used to compute a weighted sum of the Value (V) vectors
— giving the output of the attention layer. A simple example is shown below:

Multi-head attention means performing the attention operation in parallel across
multiple heads. For example, if the number of heads is set to 2, Q, K, and V are each split
into two parts—the first half of the channels form head 0, and the second half form head 1.
Each head undergoes its own attention process, producing two separate attention outputs.
Finally, these outputs are concatenated along the channel dimension to obtain the final
attention result. Fig. 8 show a simple process of Multi-head Self-Attention. In this
assignment, we set the number of head to 2 and 𝑐 = 16, √𝑐ℎ𝑒𝑎𝑑 = √8.

Hardware Design
Activation SRAM Mapping
SRAM Group A consists of four banks (A0–A3), each with 32 addresses and a data
width of 80 bits. SRAM Groups B, C, and D share the same structure as Group A but
contain 32, 48, and 64 addresses, respectively.
Each address of SRAM can store 80 bits, as each channel of a token is represented by
10 bits. Therefore, one address can hold 8 channels of a token (8 × 10 = 80 bits). To enable
parallel access, four banks are interleaved, allowing four addresses to be sent to four banks
simultaneously. By accessing all four banks in parallel, the system can read or write a
2×2@8ch token in a single cycle.

Fig. 11 SRAM data ordering in one bank and SRAM bank illustration
With the concept of SRAM group, now, we address the details of how we store output
feature maps of each layer to the SRAM group by mapping the feature maps to specific
addresses. Since the SRAM group can only store 8 channels in one address, layers with a
larger number of channels, they need to partition their feature maps along channel
dimensions and store them in different addresses. For the Q, K, and V projections, the
results are stored in SRAM Group C: addresses 0~15 for Q, 16~31 for K, and 32~48 for V.
Since the attention layer output shape is 64*64(larger them out SRAM group), we should
separate them by chunks and calculate sequentially. More details will be mentioned in the
Mutli-head self-attention implementation Section.
